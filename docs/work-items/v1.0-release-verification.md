## Scope of 1.0

The vNext model on top of `v0.1.0-beta.3`: autonomous capture with human
authority over pinned Records, the context compiler with relationship
rationale, the normalized structural provider, local activity, the Control
Room, the vNext agent workflow, migration of pre-1.0 proposals, a stable default
release channel, release builds that embed the Control Room, and the redesigned
landing and documentation. History and evidence of each phase:
[`vnext-implementation-plan.md`](vnext-implementation-plan.md) and
[`vnext-dogfood-results.md`](vnext-dogfood-results.md).

## Release artifact

`RATIONALE_VERSION=v1.0.0 ./scripts/package.sh` produced
`rationale-1.0.0-aarch64-apple-darwin.tar.xz`; its `.sha256` verifies. The
extracted binary (layout `rationale`, `LICENSE`, `README.md`):

- `--version` → `rationale v1.0.0`; `health` → provider `successful`,
  coverage complete; `doctor --check` exits 0; `conflicts` → none pending.
- `rationale ui` serves the embedded Control Room (`index.html` with the app
  root and a 1.2 MB bundle); `/api/meta` reports `v1.0.0` and 18 active
  Records. A foreign `Host` gets 421, `POST` gets 405, a traversal path gets
  400.
- MCP over stdio (`serve --client claude-code`): `serverInfo.version` `v1.0.0`;
  five tools and six prompts listed. `prepare_change` on
  `.github/workflows/release.yml` with the intent "skip the Control Room build"
  returned `constraint.release-binaries-embed-control-room` as governing;
  `explain_target` on the installer returned
  `decision.installers-default-to-stable-channel`; `finalize_change` without
  candidates wrote nothing; `resolve_conflict` without `human_answer` refused.

## Landing and documentation

Reviewed in the browser at 1440 px and 375 px, dark and light themes, English
and Spanish: no console errors and no element wider than the viewport (a
mobile clipping defect and an install-command overflow were found and fixed
during the review). Every factual claim added to the site was checked against
the binary or the code; three inaccurate statements were corrected before
committing (the updater does not remember the install channel, `resolve`
always needs an interactive terminal, `doctor` does not check MCP reachability).

## Not verified here

- Windows: compiling for `x86_64-pc-windows-msvc` from macOS stops in
  `libsqlite3-sys` (no Windows SDK headers). A static audit found no unguarded
  Unix-only API in the vNext modules; CI builds and tests Windows.
- Linux targets and the release workflow itself run only in GitHub Actions.
- Pinning and resolving a conflict live: human authority acts, covered by
  `tests/dogfood_governance_chain.rs`.
