## Úsalo al inicio de una conversación

Instala primero Codebase Memory, instala Rationale, ejecuta `rationale init` y
pega el prompt de abajo antes de pedir un cambio de código no trivial. Vive en
`docs/prompt-master.es.md`; la landing usa este mismo archivo para la versión
en español.

La versión en inglés está disponible en [master prompt](/docs/prompt-master).

## Copiar

El bloque se inyecta desde la fuente canónica durante el build para que la
documentación y el sitio no se separen del texto bilingüe.
